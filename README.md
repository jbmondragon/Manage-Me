# Manage-Me

**Manage-Me** is a web application developed to facilitate the organized tracking and management of alumni members from Batch **2020–2021**.

## Overview

The system provides administrators with comprehensive tools for maintaining member records, managing batch sections and events, monitoring registration and attendance, overseeing payment status, and generating analytical reports.

## Features

### Member Management

- Perform full create, read, update, and delete (CRUD) operations on alumni member profiles
- Monitor registration status
- Track attendance
- Record and review payment information

### Section Management

- Manage batch sections with complete CRUD functionality

### Event Management

- Create, update, and manage batch events
- Track member participation and attendance

### Analytics

The application includes analytical dashboards that provide insights on:

- Registration statistics
- Attendance trends
- Payment data
- Gender distribution
